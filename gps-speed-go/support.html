GPS Speed Go Support

Last updated: 2026-07-10

GPS Speed Go is a large GPS speed display for iPhone with Live Activity and StandBy support while charging.

How to use StandBy on iPhone

  1. Allow location access in the app.
  2. Tap Start display & prepare StandBy.
  3. Connect iPhone to power and place it on its side.
  4. Lock iPhone to enter StandBy.
  5. Tap the GPS Speed Go Live Activity to expand the speed display full screen.

Automatic start while charging

iOS does not allow third-party apps to auto-launch directly like Android screen savers. If you want charger-triggered launch, create a personal automation in the Shortcuts app and add the GPS Speed Go action.

Low-speed clock

When enabled, the display switches to a clock after speed stays below 5 km/h for one minute. This is available in the free version.

Troubleshooting

  • If speed does not update, confirm that location permission is allowed.
  • GPS accuracy is best outdoors with a clear view of the sky.
  • Live Activity updates require an active display session started inside the app.
